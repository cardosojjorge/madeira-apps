# CENTCOM Tactical Operations Center

Sistema de rastreamento em tempo real de conflitos no Médio Oriente com estética de simulação militar.

## Funcionalidades

- **Mapa tático interativo** com tiles escuros e zonas de conflito demarcadas
- **Marcadores animados** de ataques com efeitos de explosão, trilhos de mísseis e pulsos
- **Feed de eventos em tempo real** com atualização automática
- **Dashboard analítico** com gráficos de tipos de ataque, atividade temporal, forças por região e intensidade horária
- **Radar de ameaças** animado com blips de deteção
- **Alertas críticos** com classificação por severidade
- **HUD militar** com coordenadas, zoom, contagem de alvos, data/hora e estado do sistema
- **Ecrã de arranque** (boot sequence) simulando inicialização de sistema militar
- **Efeitos visuais** — scanlines, flash de ecrã em eventos críticos, animações CSS

## Tecnologias

- **Leaflet.js** — Mapa interativo
- **Chart.js** — Gráficos e visualizações
- **HTML/CSS/JS puro** — Sem frameworks, zero dependências de build

## Como usar

Abrir `index.html` num browser moderno. Todas as dependências são carregadas via CDN.

## Dados

Os dados são simulados em tempo real com geração procedural de eventos de conflito em várias regiões do Médio Oriente.
